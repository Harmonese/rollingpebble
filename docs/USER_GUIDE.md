# 使用指南

[文档索引](README.md) · [存储与清理](STORAGE.md)

## 导入和临时工作区

点击“导入音频”选择本地文件。音频在当前窗口中准备、读取标签并播放，**不会因此创建工程或向项目目录复制音频**。文件名和标签文字可以发送给本地服务以应用已配置的文件名规则，音频文件本身不会在此时上传。

导入本地歌词或从歌词库选择歌词后，可以编辑文本、手动打轴及直接导出 LRC。工程面板始终使用相同的字段布局，通过 Project Status 显示 Saved 或 Unsaved；首次保存前 ID 显示为“-”。浏览器可能缓存编辑器文本，但这不等于保存工程；未保存音频不会在关闭、刷新或重新启动后自动恢复。

导入歌词保留音频和已有元数据；导入文件显式提供的标签覆盖对应字段。新歌词会清空旧标记和撤销记录。在线音频试听仅影响播放器，不替换工程内保存的本地音频。

导入音频只替换当前音频，保留歌词、时间戳、标记和歌词来源，不弹出工作区切换确认。已有标题、歌手和专辑保留，空字段由音频标签补充，时长随音频更新。保存工程或启动自动打轴时才保存替换后的音频；已保存工程保留原 ID。打开其他工程时，未保存内容仍会询问“保存工程”“放弃修改”或“取消”。

自动打轴或批量任务运行期间，可以在界面更换音频，但保存替换需等待任务结束。替换保存后清除旧音频的自动打轴缓存，已有歌词和时间戳保留。

## 保存工程

“Project List／工程列表”下的“保存工程”按钮保存当前音频（如有）、歌词、元数据和歌词来源。首次保存后工程才出现在列表中。再次保存更新同一工程，不重新复制原音频。只有歌词时也可以保存工程。

保存失败时当前工作区保留，修正问题后可重试。首次保存采用完整写入后再发布目录的方式；同一临时工作区的重复创建请求不会生成多个工程。保存过程中继续编辑的内容仍需再次保存，保存成功不会重置编辑器。

## 手动打轴

切换到同步器，选择歌词行并播放音频，用 Space 写入时间戳。播放器控制不会主动写入时间戳。

| 操作 | 快捷键 |
| --- | --- |
| 插入时间戳 | Space |
| 移除时间戳 | Backspace / Delete |
| 播放／暂停 | Ctrl / ⌘ + Enter |
| 后退／前进 5 秒 | ← / →，也支持 A / D 和 H / L |
| 后退／前进 1 秒 | Alt / Option + ← / → |
| 后退／前进 2.5 秒 | Shift + ← / → |
| 后退／前进 0.5 秒 | Alt / Option + Shift + ← / → |
| 上一行／下一行 | ↑ / ↓，也支持 W / S 和 J / K |
| 调整当前行时间戳 | - / + |
| 提高／降低播放速度 | Ctrl / ⌘ + ↑ / ↓ |
| 重置播放速度 | R |

在文本输入框中输入时，工作区快捷键会让位于文本编辑。确认对话框打开时，按键不会传到背景同步器。上述快捷键未在本次工作区改造中更改。

## 自动打轴

先在设置中安装或检查隔离运行环境，并准备所需模型。未保存音频也可点击开始：应用先检查输入和环境，再保存当前工程并提交任务。更改参数和查看预览不会创建工程；完整命令预览需要已保存工程。

运行失败后，已保存的工程保留，重试复用该工程。任务结果写入发起任务的工程；如果你已切换工作区或继续修改歌词，结果不会自动覆盖当前编辑内容，可从原工程重新打开查看。批量自动打轴从已保存工程中选择输入。

## 导出与发布

同步器的下载按钮可直接导出 LRC，无须先创建工程。LRCLIB 发布需要先保存工程，再生成发布方案并确认上传；生成方案不会隐式创建新工程。

## 删除与确认

删除、迁移位置及恢复默认设置使用应用内确认框，浏览器和桌面应用使用同一套界面。Esc 取消最上层对话框，取消不会继续执行操作。

工程列表删除确认后有 **10 秒撤销窗口**。设置中的存储清理没有此撤销窗口。删除当前工程成功后会清空其当前工作区和音频引用。关闭窗口前仍需保存希望保留的工作。

自动删除设置的触发时机、保护范围及不可恢复性见[存储说明](STORAGE.md)，它与列表的延迟删除不同。

## 重复歌词标记

同步器顶栏右侧的 Mark 将选中行文本追加为标记，相同文本只保留一个。Unmark 删除与选中行文本相同的标记，不删除歌词。Editor 模式下这两个按钮禁用。

标记编号按 Mark 操作顺序排列，与歌词行顺序无关。Synchronizer 中匹配标记文本的歌词行显示对应编号，与顶部数字栏保持一致；删除标记后编号连续重排。

有标记时，顶栏下方显示右对齐的紧凑数字按钮，从 1 连续编号，数量不限，超出宽度可横向滚动；删除后连续重排。歌词行右侧显示相同样式的编号，未标记行不预留编号空间。点击数字在选中行上方插入标记文本，并使用当前播放时间作为时间戳，保持选中原来的待打轴行，连续插入按操作顺序排列。悬停显示文本和快捷键。标记保存文本快照，在编辑器和同步器之间切换时保留，导入新歌词、切换工程或刷新时清空，不写入 LRC。

最后一行打轴后，自动选中并滚动到末尾空白占位行，继续插入会追加歌词并保持选中占位行。占位行不保存、不导出，也不能标记、删除或打轴。

Ctrl/⌘ + 数字设置标记：位置存在则替换，不存在则追加，不留空位，已有文本不重复设置。Alt/Option + 数字插入标记，Ctrl/⌘ + Shift + 数字按编号删除标记。快捷键仅对应前 10 个，第 10 个按钮显示 10，物理按键使用 0。长按不会重复执行。

裸按 1 选中并滚动到正在播放的歌词行，不改变播放位置；没有匹配行时不操作。Ctrl/⌘ + Delete 或 Backspace 删除选中的整行，选中后继行，删除末行后选中占位行；单独 Delete / Backspace 仍只清除时间戳。

Ctrl/⌘+Z 按操作顺序撤销插入或整行删除，并恢复选中位置（共最多 100 次）；修改时间戳或在编辑器中修改歌词后，该撤销记录清空，避免撤回后续编辑。删除歌词不删除已有标记快照。标记操作本身不改变保存状态，歌词插入、删除和撤销参与正常工程保存和导出。输入框及应用对话框中不触发这些快捷键。原有裸按 0 的行为不变。
