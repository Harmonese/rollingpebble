# 使用指南

[文档索引](README.md) · [存储与清理](STORAGE.md)

## 歌词翻译

Translation 设置中的提示词可直接编辑。英文默认提示词强调凝练自然的歌词表达、意象与双关、重复句一致性，并检查否定、指代及跨行语义；不随界面语言变化。已有提示词不会被升级覆盖；“恢复默认提示词”填回新版默认内容，点击保存后生效。修改只影响后续请求，运行中的任务使用开始时的提示词。逐句 ID 对应和 JSON 输出要求由程序保留，不能通过提示词取消。

在 Settings → Translation 配置兼容的 API Base URL（包括服务要求的 `/v1`）、模型名称和可选密钥。本地及局域网服务支持 HTTP，远程服务使用 HTTPS。代理独立于模型下载设置，留空即直连；仅支持不含嵌入式凭据的 HTTP(S) 代理。Test Connection 会发送一条简短模型请求，不发送歌词。密钥保存到系统凭据库；不可用时明确显示仅当前会话保存，不写入普通偏好文件。

点击 Editor 工具栏的翻译图标显示或隐藏双栏；显示本身不会请求模型。选择源语言与目标语言，Translate 翻译整首，重译选中行只更新一行，但同样提供全曲和标题、艺人、专辑作为上下文。不会发送音频或文件路径。模型质量由所选服务决定，建议校订双关、引用及含混句子。

双栏是两块连续的 LRC 文本编辑器，左右均显示时间戳，可单侧全选、跨行选择和复制。长句自动折行，两侧对应句子保持等高并同步滚动；对齐留白不会进入复制或导出内容。左侧可修改时间戳，右侧同步显示但不能独立修改时间。未完成或无效的时间戳必须修正后才能保存或离开编辑区。

两侧可修改已有句子，支持覆盖相同行数的多行粘贴；新增、删除、拆分和合并请回到普通 Editor。右侧可粘贴纯译文，带时间戳的译文需与原文一致。Ctrl/⌘+Z 撤销双栏编辑，Ctrl/⌘+Shift+Z 重做；载入新文档、外部翻译结果或退出双栏后重置本次编辑历史。改原句会以边缘标记提示译文待更新，悬停查看；人工校订译文后解除。普通 Editor 无法确定对应关系的整段编辑需确认清除受影响译文，并可在下一次文档修改前撤销。替换音频保留译文，新歌词或自动打轴结果替换文档时确认清除。Synchronizer 可单独显示或隐藏次级译文，Auto Timing Review 不提供翻译入口。

翻译完成后直接更新工作区：已有工程自动保存；临时工作区仍需首次 Save Project 才建立工程。切换目标语言的整首翻译成功前保留旧译文；单行重译需保持当前译文语言。两侧标题旁的复制、下载按钮分别导出原文和译文，缺失译文不补空句。Editor 顶部原有复制与下载按钮始终操作原文。

请求期间可以继续编辑；修改原文、译文、结构或语言后，旧结果不再应用。单纯调整时间、播放、选择及隐藏双栏不影响请求。Cancel 等待本地连接关闭，但不能保证服务端停止处理或计费。翻译任务只在当前应用会话保留，重启不自动重发。

## 导入和临时工作区

点击“导入音频”选择本地文件。音频在当前窗口中准备、读取标签并播放，**不会因此创建工程或向项目目录复制音频**。文件名和标签文字可以发送给本地服务以应用已配置的文件名规则，音频文件本身不会在此时上传。

导入本地歌词或从歌词库选择歌词后，可以编辑文本、手动打轴及直接导出 LRC。工程面板始终使用相同的字段布局，Project Status 显示未保存、保存中、已保存或保存失败；首次保存前 ID 显示为“-”。临时工作区的恢复数据不等于已保存工程，也不会出现在工程列表中。

导入歌词保留音频和已有元数据；导入文件显式提供的标签覆盖对应字段。新歌词会清空旧标记和撤销记录。网易云音频导入同样进入临时工作区，保存时才写入工程。

开始另一首歌时，点击 **New Project／新建工程**，再导入音频。新建会清空当前工作区，但不立即创建磁盘工程；已有工程先等待保存，临时工作区可选择保存、放弃或取消。旧工程和自动打轴结果仍保留。

已有音频时，导入按钮改为 **Replace Audio／替换音频**，用于更换同一工程的音源；歌词、时间戳、标记和歌词来源保留。由音频自动填写的标题、艺人和专辑随新文件更新，手动编辑或歌词导入的信息保留，包括主动清空的字段；时长随音频更新。这些字段来源随工程保存。旧工程没有来源记录时，已有信息按受保护信息处理。

已有工程替换音频后自动保存，保留原 ID。切换工程前等待保存完成；临时工作区则询问“保存工程”“放弃修改”或“取消”。

自动打轴使用任务专属音频快照。运行期间更换音频不会改变任务输入；旧预览仍可查看和导出，但不能使用新音频给旧结果打轴，也不能直接应用到不同音频的工作区。

## 保存工程

Project 面板中与“新建工程”并列的“保存工程”按钮保存当前音频（如有）、歌词、元数据和歌词来源。首次保存后工程才出现在列表中。再次保存更新同一工程，不重新复制原音频。只有歌词时也可以保存工程。

首次保存后，停止编辑约 1 秒会自动保存，连续编辑最长约 10 秒保存一次有效内容。`Ctrl/⌘ + S` 可立即保存，包括 Editor 内正在编辑的内容。保存失败时保留修改，点击重试；无效时间戳需要先修正。自动保存不是版本历史，不能靠关闭窗口放弃已自动保存的修改。

应用只保留一份当前工作区恢复数据，包括歌词、译文、元数据、未提交文本和待保存音频。音频临时副本在保存成功后清理。启动会重新打开上次工程；有未完成工作时询问恢复或丢弃。桌面关闭窗口或退出时等待工程和审阅草稿保存，失败可重试、放弃或取消；临时工作区先询问保存。强制退出后只能恢复最近完成的恢复快照，不保证最后一次输入已经落盘。

保存失败时当前工作区保留，修正问题后可重试。首次保存采用完整写入后再发布目录的方式；同一临时工作区的重复创建请求不会生成多个工程。保存过程中继续编辑的内容仍需再次保存，保存成功不会重置编辑器。

## 手动打轴

切换到同步器，选择歌词行并播放音频，用 Space 写入时间戳。播放器控制不会主动写入时间戳。

| 操作 | 快捷键 |
| --- | --- |
| 插入时间戳 | Space |
| 移除时间戳 | Backspace / Delete |
| 播放／暂停 | Ctrl / ⌘ + Enter |
| 后退／前进 5 秒 | ← / →，也支持 A / D 和 H / L |
| 后退／前进 1 秒 | Alt / Option + ← / → |
| 后退／前进 2.5 秒 | Shift + ← / → |
| 后退／前进 0.5 秒 | Alt / Option + Shift + ← / → |
| 上一行／下一行 | ↑ / ↓，也支持 W / S 和 J / K |
| 调整当前行时间戳 | - / + |
| 提高／降低播放速度 | Ctrl / ⌘ + ↑ / ↓ |
| 重置播放速度 | R |

在文本输入框中输入时，工作区快捷键会让位于文本编辑。确认对话框打开时，按键不会传到背景同步器。上述快捷键未在本次工作区改造中更改。

## 自动打轴

Auto Timing 保留 Experimental 标识，语言默认自动，也可选择英文、普通话、中英混唱或多语言。自动按歌词文字选择后端，不从歌声辨认语言或方言；普通话不包含粤语。普通话、多语言为实验性支持，中英混唱的真实歌曲质量仍待验收。简繁规范化和音素仅用于内部处理，审阅和导出保留原文。

桌面启动使用同一画面依次检查环境、必要时准备组件、校验模型，再进入工作区。环境检查或准备使用不定进度；模型校验、下载及下载后校验分别显示当前阶段的实际字节进度。环境失败时可修复，或直接进入工作区手动编辑。首次安装可选择英文、普通话和多语言准备项，可多选；中文界面初始选普通话，其他界面初始选英文。下载共享 Whisper、所选 CTC 和 Demucs，不改变自动对齐语言默认值。后续启动检查所有已安装模型；只要有一个 CTC 通过校验（包括已配置的外部 CTC），便不再提醒安装其他缺失的 CTC。已安装模型损坏或检查失败，以及所选 Whisper、Demucs 缺失仍会提示。实际对齐仍须安装该语言对应的 CTC，可在设置中按需下载。“稍后”或关闭询问只跳过本次，后续启动仍会提醒尚未解决的问题。

下载默认使用国内源 ModelScope，也可选择国际官方源；两种来源安装相同版本的模型，不保留两份。代理默认关闭，启用后填写 HTTP／HTTPS 代理地址；下载来源、代理及超时统一位于设置的模型区域。下载显示实际字节进度，可取消并在下次继续，已有正常模型不会重复下载。下载失败不自动切换来源，也不破坏原模型。

每次桌面启动会离线完整校验已安装模型的 SHA-256，并在底部显示进度。从未安装、主动删除和意外丢失都显示“未安装”；哈希不符显示“损坏”，无法读取或检查显示“检查失败”。只下载或修复受影响的模型。可跳过本次校验，取消后会等待任务退出再进入工作区；尚未验证的模型不能用于自动打轴，需要在设置中完成校验。仅 Demucs 异常时，Original 仍可使用。外部 Whisper 路径共用，三种 CTC 路径分别配置并通过引擎兼容性检查；旧自定义 CTC 路径只用于英文。外部路径，异常时提示检查配置，不要求下载对应受管理副本，也不修改外部目录。下载超时为每次网络等待 1–30 秒。

默认音源为 Original，线程数为 4，推理始终离线，点击 Start 不会下载模型。选择 Vocals 后会自动补齐软件依赖，缺少 Demucs 时需要先下载模型。CTC 可选择 Auto、CPU 或 MPS；Whisper 和 Demucs 使用 CPU。多语言发音组件随应用提供，用户不需要安装 Homebrew。点击 Start 后先按当前歌词确定语言，只要求对应 CTC；批量 Auto 按每首分别判断。

准备时显示“准备中”，失败时才显示修复入口；详细版本和日志收在 Diagnostics 中。关闭设置不终止组件准备。Start 等待期间可以取消启动意图；更换工程、音频、歌词或选项后，不会自动启动旧请求，需要重新点击 Start。修复仅修复组件，不会自动启动推理，也不删除模型、工程或草稿。

点击 Start 先保存当前工程，再检查输入、模型与环境并提交任务。更改参数或查看结果不会创建工程。每次运行和重试都有独立结果，不会自动写入工程歌词。批量模式串行处理选中的已保存工程；单曲运行失败后继续下一首，取消会等待当前进程退出并取消后续项。结果历史可重新打开批量任务，重试失败项或继续未完成项；重启不会自动恢复执行。

Alignment Mode 可选择 Ordered（按歌词顺序）或 Unordered（不限定顺序）。Ordered 要求输入完整歌词并保留每次重复；Unordered 适合来源歌词省略重复句的情况。新安装默认 Ordered，升级时已有设置保留 Unordered。单曲和批量都显式使用所选模式。

Ordered 的已定位与未定位歌词在审阅中按提交顺序显示。未定位行没有时间戳，可手动补轴；Apply、保存和审阅导出均保留这些行。引擎原始 LRC 只包含已定位行。未定位数量随当前草稿变化，完成不代表每行都已定位。

开始任务或打开历史结果后，中央顶栏出现 Auto Timing Review（自动打轴审阅），不会主动切换当前视图。预览可使用同步器和文本编辑器，标记、选择和撤销与主工作区独立。尚无快照时只显示处理阶段；首次预览需要等待 CTC 和首个 Whisper 窗口完成。更换音频后，旧结果保留为只读审阅：同步器和编辑器仍可切换，可选择、复制和导出，但不能打轴、修改或 Apply；音频重新匹配后恢复编辑。

预览默认跟随引擎快照。第一次修改歌词或时间后成为独立草稿，后续快照不覆盖编辑；选择、播放和标记不冻结草稿。草稿自动保存到任务记录，刷新或重启后可以从结果历史恢复。Use Latest 经确认后放弃草稿并载入最新结果。保存失败时显示错误，需重试或导出后再切换结果。

完成后点击 Apply 更新当前工作区，并按已有工程的自动保存规则持久化。应用保留音频和元数据，并清空原歌词的标记和插入／删除撤销记录。工作区歌词已修改、结果为空或任务失败／取消时会询问确认；未成功结果标为 Partial，不会变成成功任务。处理中不能 Apply。可导出当前预览，包括独立草稿或部分结果。

结果历史中的删除操作删除该结果及草稿，保留工程。Auto Timing 设置统一负责模型下载与删除、网络及默认运行参数。Storage 只提供一个数据位置和工程、模型、结果、缓存、应用组件五类占用；工程和结果通过管理弹窗删除，缓存单独清理，组件由应用管理。更换位置迁移整个数据目录，成功后删除旧副本；恢复默认设置不更换位置。工程不再自动过期删除。模型下载不提供虚构百分比，任务阶段进度也不拼成全程准确率。

## 导出与发布

同步器的下载按钮可直接导出 LRC，无须先创建工程。LRCLIB 发布需要先保存工程，再生成发布方案并确认上传；生成方案不会隐式创建新工程。

## 删除与确认

删除、迁移位置及恢复默认设置使用应用内确认框，浏览器和桌面应用使用同一套界面。Esc 取消最上层对话框，取消不会继续执行操作。

工程列表删除确认后有 **10 秒撤销窗口**。设置中的存储清理没有此撤销窗口。删除当前工程成功后会清空其当前工作区和音频引用。关闭窗口前仍需保存希望保留的工作。

自动删除设置的触发时机、保护范围及不可恢复性见[存储说明](STORAGE.md)，它与列表的延迟删除不同。

## 重复歌词标记

同步器顶栏右侧的 Mark 将选中行文本追加为标记，相同文本只保留一个。Unmark 删除与选中行文本相同的标记，不删除歌词。Editor 模式下这两个按钮禁用。

标记编号按 Mark 操作顺序排列，与歌词行顺序无关。Synchronizer 中匹配标记文本的歌词行显示对应编号，与顶部数字栏保持一致；删除标记后编号连续重排。

有标记时，顶栏下方显示右对齐的紧凑数字按钮，从 1 连续编号，数量不限，超出宽度可横向滚动；删除后连续重排。歌词行右侧显示相同样式的编号，未标记行不预留编号空间。点击数字在选中行上方插入标记文本，并使用当前播放时间作为时间戳，保持选中原来的待打轴行，连续插入按操作顺序排列。悬停显示文本和快捷键。标记保存文本快照，在编辑器和同步器之间切换时保留，导入新歌词、切换工程或刷新时清空，不写入 LRC。

最后一行打轴后，自动选中并滚动到末尾空白占位行，继续插入会追加歌词并保持选中占位行。占位行不保存、不导出，也不能标记、删除或打轴。

Alt/Option + 数字设置标记：位置存在则替换，不存在则追加，不留空位，已有文本不重复设置。Ctrl/⌘ + 数字插入标记，Ctrl/⌘ + Shift + 数字按编号删除标记。快捷键仅对应前 10 个，第 10 个按钮显示 10，物理按键使用 0。长按不会重复执行。About 列出了标记、打轴、行导航、播放与速度控制的常用快捷键。

裸按 1 选中并滚动到正在播放的歌词行，不改变播放位置；没有匹配行时不操作。Ctrl/⌘ + Delete 或 Backspace 删除选中的整行，选中后继行，删除末行后选中占位行；单独 Delete / Backspace 仍只清除时间戳。

Ctrl/⌘+Z 按操作顺序撤销插入或整行删除，并恢复选中位置（共最多 100 次）；修改时间戳或在编辑器中修改歌词后，该撤销记录清空，避免撤回后续编辑。删除歌词不删除已有标记快照。标记操作本身不改变保存状态，歌词插入、删除和撤销参与正常工程保存和导出。输入框及应用对话框中不触发这些快捷键。原有裸按 0 的行为不变。
