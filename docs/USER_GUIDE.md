# 使用指南

[文档索引](README.md) · [存储与清理](STORAGE.md)

## 导入和临时工作区

点击“导入音频”选择本地文件。音频在当前窗口中准备、读取标签并播放，**不会因此创建工程或向项目目录复制音频**。文件名和标签文字可以发送给本地服务以应用已配置的文件名规则，音频文件本身不会在此时上传。

导入本地歌词或从歌词库选择歌词后，可以编辑文本、手动打轴及直接导出 LRC。工程面板始终使用相同的字段布局，通过 Project Status 显示 Saved 或 Unsaved；首次保存前 ID 显示为“-”。浏览器可能缓存编辑器文本，但这不等于保存工程；未保存音频不会在关闭、刷新或重新启动后自动恢复。

导入另一首音频会进入新工作区，不覆盖旧工程。如果当前内容尚未保存，会询问“保存工程”“放弃修改”或“取消”。打开已有工程也遵循相同规则。

## 保存工程

“Project List／工程列表”下的“保存工程”按钮保存当前音频（如有）、歌词、元数据和歌词来源。首次保存后工程才出现在列表中。再次保存更新同一工程，不重新复制原音频。只有歌词时也可以保存工程。

保存失败时当前工作区保留，修正问题后可重试。首次保存采用完整写入后再发布目录的方式；同一临时工作区的重复创建请求不会生成多个工程。保存过程中继续编辑的内容仍需再次保存，保存成功不会重置编辑器。

## 手动打轴

切换到同步器，选择歌词行并播放音频，用 Space 写入时间戳。播放器控制不会主动写入时间戳。

| 操作 | 快捷键 |
| --- | --- |
| 插入时间戳 | Space |
| 移除时间戳 | Backspace / Delete |
| 播放／暂停 | Ctrl / ⌘ + Enter |
| 后退／前进 5 秒 | ← / →，也支持 A / D 和 H / L |
| 后退／前进 1 秒 | Alt / Option + ← / → |
| 后退／前进 2.5 秒 | Shift + ← / → |
| 后退／前进 0.5 秒 | Alt / Option + Shift + ← / → |
| 上一行／下一行 | ↑ / ↓，也支持 W / S 和 J / K |
| 调整当前行时间戳 | - / + |
| 提高／降低播放速度 | Ctrl / ⌘ + ↑ / ↓ |
| 重置播放速度 | R |

在文本输入框中输入时，工作区快捷键会让位于文本编辑。确认对话框打开时，按键不会传到背景同步器。上述快捷键未在本次工作区改造中更改。

## 自动打轴

先在设置中安装或检查隔离运行环境，并准备所需模型。未保存音频也可点击开始：应用先检查输入和环境，再保存当前工程并提交任务。更改参数和查看预览不会创建工程；完整命令预览需要已保存工程。

运行失败后，已保存的工程保留，重试复用该工程。任务结果写入发起任务的工程；如果你已切换工作区或继续修改歌词，结果不会自动覆盖当前编辑内容，可从原工程重新打开查看。批量自动打轴从已保存工程中选择输入。

## 导出与发布

同步器的下载按钮可直接导出 LRC，无须先创建工程。LRCLIB 发布需要先保存工程，再生成发布方案并确认上传；生成方案不会隐式创建新工程。

## 删除与确认

删除、迁移位置及恢复默认设置使用应用内确认框，浏览器和桌面应用使用同一套界面。Esc 取消最上层对话框，取消不会继续执行操作。

工程列表删除确认后有 **10 秒撤销窗口**。设置中的存储清理没有此撤销窗口。删除当前工程成功后会清空其当前工作区和音频引用。关闭窗口前仍需保存希望保留的工作。

自动删除设置的触发时机、保护范围及不可恢复性见[存储说明](STORAGE.md)，它与列表的延迟删除不同。
